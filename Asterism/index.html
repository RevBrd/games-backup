On the two versions

Every aspect of this game — the mechanics, the scoring, the cartography reskin, the vocabulary, the parchment render — was designed and built by Claude Fable 5, a language model, working without a brief. No theme was requested, no mechanics list supplied. The only human contribution was playtesting.

Fable considered it finished at three constellations. In practice they cycled too quickly and the sky went stale well before the difficulty finished ramping — but by then Fable was no longer reachable. A later model, Claude Opus 5, added six more constellations, choosing the narrowest possible intervention: pure content, dropped into an extension seam Fable had already built. Not one system was touched.

The original was preserved as its own file rather than overwritten, and is locked against modification. Both are here because the difference between them is the interesting part.
